# Java Programming

A collection of beginner-friendly Java programs covering fundamental programming concepts.

## Topics

- Classes and objects: `Student`, `Circle`, and `Rectangle`
- Loops: `ForLoop` and `WhileLoop`
- Arithmetic programs: factorial, sum of numbers, and marks

## Files

| File | Description |
| --- | --- |
| `Student.java` | Demonstrates a student class and its properties. |
| `Circle.java` | Demonstrates calculations related to a circle. |
| `Rectangle.java` | Demonstrates calculations related to a rectangle. |
| `ForLoop.java` | Examples using a `for` loop. |
| `WhileLoop.java` | Examples using a `while` loop. |
| `Factorial.java` | Calculates a factorial. |
| `Sumofno.java` | Calculates the sum of numbers. |
| `marks.java` | Contains a marks-related program. |
| `Main.java` | Additional Java program entry point. |

## Run a program

Compile a source file from this folder:

```powershell
javac Student.java
```

Run the compiled class:

```powershell
java Student
```

Use the same pattern for other programs, replacing `Student` with the relevant class name.
